GORGON / FIRST INTEGRATION

A score for sound and movement.

Video comes from the running HydraPy patch. Three automation lanes control the named parameters you bind. Audio is a browser synth sketch; archive samples, Stable Audio and Deforum inference are not connected.

Compose

Click audio cells to edit hits. Select visual cells and use the sliders or curve to write keys. Hold, Linear and Smooth choose interpolation. The included patch maps Dolly Z to 2D zoom and Roll to rotation.

Perform

Space starts automation or pauses. F enters fullscreen. B blacks out browser monitors. Seeking moves the score only: simulation time and feedback continue. Disable automation to return control of parameters to Studio.

More displays

Program and Auxiliary each show a real output. Open a window, move it to its monitor, then press F. The renderer keeps running when the control window closes. Browser audio comes only from the control surface and stops when it closes.

Save & export

Save writes a workspace score and downloads JSON. Import accepts a saved score; Restore loads the workspace copy. Studio video exports include enabled visual automation, but do not include the browser synth. Recording and snapshots use the actual selected output.
