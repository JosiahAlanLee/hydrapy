GORGON / EDITOR GUIDE
Compose, edit, then perform.


Video comes from the running HydraPy patch. Three automation lanes control the named parameters you bind. Audio is a browser synth sketch; archive samples, Stable Audio and Deforum inference are not connected.


Use the Hydra monitor’s o0–o3 buttons to inspect outputs, or [ and ] to cycle them. Program follows the live feed again; the dot marks its current output. Preview selection stays local to this tab. Program and Auxiliary routing choose the feeds sent to your output windows.


1. Navigate and enter notes
Choose Audio for notes or Visual for automation and Scene. Tab in the grid switches pages at the same pattern and row; Shift+Tab leaves the grid. Tab in a form navigates fields normally. Click a cell or use arrows. Selection never seeks playback. Enable Piano keys, focus an audio cell, then use Z S X D C V G B H N J M for one octave and Q 2 W 3 E R 5 T 6 Y 7 U for the next. Octave and Advance set entry behavior. Enter toggles a hit without advancing; Delete clears. Sound must be on to hear entry.
2. Edit a block
Shift+click, Shift+arrows or drag across cells. Ctrl/Cmd+A selects every lane on the current page. Switching pages clears the selection. Delete and Paste affect visible lanes only; Undo/Redo returns to the page of that edit. Copy, Cut and Paste work with notes and automation keys; automation pastes into the same kind of lane. Pitch buttons or Alt+Up/Down transpose notes. Apply velocity changes existing notes. Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z redoes.
3. Shape and arrange
Banks A–H hold sixteen patterns each; the chain plays them in order, and ↻ loops the one you edit instead. Rate, Bar and Bars set a pattern’s speed and length; a lane can be shorter and repeat (its Length), and Transforms reshape it (rot, rev, ply, degrade, every). A cell’s Condition decides when it plays: 1:4 on the first bar of four, %50 half the time, F while FILL is on, 1ST on a pattern’s first bar, ! for the opposite. Select a visual cell and write a value or click the curve. Hold, Linear and Smooth set interpolation for that lane in the pattern. Bind lanes to named patch controls. Pattern tools renames, copies or clears a pattern. Cards show actual note and key activity. Select a card to edit; its separate ▶ button launches it. Follow tracks playback and can be turned off to edit another pattern.
4. Perform and save
Space plays or pauses. Seek to row moves playback explicitly and preserves feedback. F enters fullscreen; B blacks out browser monitors and the fullscreen output. On Linux, Display › Show Program fullscreen (Shift+F) puts Program on another monitor straight from the GPU; edits and cues reach it at the next refresh, and the monitor here becomes a small preview. In the note grid with Piano keys on, B enters a note; use the Blackout button instead. Open Program and Auxiliary on other monitors. File contains import, restore, a new empty score and a recovery download. Ctrl/Cmd+S saves the workspace score and downloads JSON.


The browser synth is a sketch and is not included in Studio exports. Output windows and the renderer keep running when this controller closes.
